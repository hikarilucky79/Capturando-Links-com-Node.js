# ✦ Capturando Links com Node.js ✦

**Web scraping & link extraction tool**

</div>

---

## Sobre

Ferramenta CLI que extrai e organiza links de páginas web usando Node.js. Demonstra scraping e processamento de HTML de forma eficiente.

## Funcionalidades

- Extração de todos os links de uma URL
- Filtro por domínio
- Output formatado e organizado
- Tratamento de URLs relativas e absolutas

## Tech Stack

- **Node.js** — Runtime JavaScript
- **Cheerio** — Parsing de HTML
- **Axios** — Requisições HTTP

## Como Rodar

```bash
# Instalar dependências
npm install

# Extrair links de uma página
node index.js <url>
```

## Exemplo

```bash
node index.js https://example.com
```
